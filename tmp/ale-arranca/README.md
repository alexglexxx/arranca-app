# Arranca

Arranca is a pilot PWA for short-term gasoline loans for app drivers.

Its core flow covers:

- Phone login with Firebase Auth.
- KYC upload in mobile web.
- Loan request and manual admin review.
- Manual payment confirmation.
- Referral rewards.

## Current Known Focus

- Keep the backend as the single source of truth for credit, KYC, and capital operations.
- Preserve security hardening and prevent trust in client-provided identifiers.
- Record financial, identity, and admin-risk decisions before future product growth.
